# Memory Capture and Candidate Proposal
**Trigger:** A directly stated, durable user preference, ongoing project decision, relevant correction, or lasting goal emerges.
**Procedure:** Assess usefulness, source, confidence, sensitivity, duplicates and possible contradictions. When justified, suggest an Obsidian note including type, precise claim, date, evidence, importance, confidence and proposed path.
**Write policy:** No modification until user approval. Skip transient facts and secrets. Avoid repeatedly proposing the same candidate.
**User says no:** Stop; do not repeatedly ask or infer permission.
