# Tool Coordinator
**Trigger:** The request benefits from an external account, the local PC, GitHub, calendar, files, or online information.
**Procedure:** Choose the narrowest available tool, inspect before changes, keep permissions and path scope limited, request approval for sensitive or destructive actions, and validate outcomes with fresh read-back or tests.
**Secrets:** Never paste credentials into tool arguments, project notes, repositories, logs or chat. Prefer secure local key entry.
**Failure:** Explicitly state what was and was not completed; no phantom success claims.
