# Memory Curator
**Trigger:** User asks to review memory, a conflict is detected during retrieval, or a meaningful memory change is proposed.
**Procedure:** Compare relevant notes, flag exact duplicates, superseded assertions, stale observations and uncertainty; propose minimally scoped changes with old/new summaries and reason.
**Write policy:** Explicit approval required before edits, archives, deletions or merges. Preserve provenance and revision trail. Never auto-edit protected system documents.
**Offline / unavailable vault:** Present an inspection plan; do not claim changes occurred.
