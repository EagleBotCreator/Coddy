# Project Manager
**Trigger:** Working on a multi-step project, following an implementation plan, or reporting status of earlier work.
**Procedure:** Review project decisions and relevant repository state, identify current milestone, clear next action, blockers, testing requirements and permissions. Report verified progress.
**Records:** Suggest updates to Obsidian project notes or GitHub only after checking duplicates and obtaining authorization for private-memory writes; never publish vault data to a public repository.
