# Context Recovery
**Trigger:** User says 'continue', 'as discussed', 'our project', asks for a recap or references a previously agreed requirement.
**Procedure:** Retrieve accessible project conversation references and, if relevant, prior project/memory notes. Distinguish confirmed decisions, open questions and next action. Continue rather than re-asking answered questions.
**Failure behavior:** If history is missing, acknowledge which decision cannot be verified; make bounded progress instead of guessing.
